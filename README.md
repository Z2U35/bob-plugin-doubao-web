# 豆包网页翻译 · Bob 插件

让 Bob 使用豆包网页端翻译。**不需要 API Key**，支持豆包、豆包·火山、豆包·微软三种翻译选项。

> **v0.2.0 测试预览版，非官方作品。** 已完成协议、客户端、原生助手安全边界测试与匿名接口探测；尚未完成真实账号扫码后在 Bob 内翻译成功的验收。网页端协议、扫码入口及 WebKit 兼容性可能变化，不能保证任何账号都能使用。

## 安装

### 推荐：官方网页登录，自动获取登录态

1. 下载并解压登录助手，把 **Doubao Login Helper.app** 拖到「应用程序」后打开。
2. 在助手窗口里的 **豆包官方网站** 登录。官网提供扫码时扫码；若要求手机号或验证码，按官网提示完成。助手不提供自制二维码，也不会替你绕过登录、验证码或设备确认。
3. 双击 `.bobplugin` 文件安装，在 Bob 中添加「豆包网页翻译」文本翻译服务。保持「登录方式」为「自动」，**Cookie 输入框留空**。
4. 点 Bob 的「验证」。首次连接会出现 **6 位配对码**，助手也会显示相同的码。核对一致后，在助手中点击「允许配对」。**若不是自己刚刚发起的验证，不要允许。**
5. 回 Bob 再点一次「验证」。这次会自动读取助手登录态，并发送 `Hello, world!` 到豆包测试翻译。
6. 验证通过后即可划词或使用你原有的 OCR 服务识别后翻译。

之后只要助手在运行、登录态有效，就不用再找 Cookie。关掉登录窗口不会退出助手，菜单栏仍有「豆包登录」；选择「退出登录助手」才会停止本机连接。没有默认添加开机启动项。

**自动化边界：** Bob 没有公开的“插件设置打开时启动浏览器”钩子，本插件是在验证或翻译请求时读取会话；助手没有启动时会提示先打开。首次需要安装助手和一次配对确认，不能诚实地承诺“只装一个 `.bobplugin` 就直接扫码”。

### macOS 提示无法验证开发者？

当前助手只有 **ad-hoc 签名，没有 Apple Developer ID 签名或公证**。从 GitHub 下载后，macOS 可能拦截。

请先核对下载来源、源码和 `SHA256SUMS.txt`，再按 macOS 的「隐私与安全性」提示允许打开。**不要全局关闭 Gatekeeper。** 如果设备由公司管理、禁止未公证应用，使用手动 Cookie 模式，或按开发说明在本机从源码构建。

### 备用：手动 Cookie

如官方登录页在 WebKit 中无法正常加载，可以不使用助手：

1. 在浏览器登录 `https://www.doubao.com/`。
2. 打开开发者工具 → **Network / 网络**，刷新网页。
3. 选择一条发往 `www.doubao.com` 的实际请求，找到 **Headers → Request Headers → Cookie**。
4. 复制 Cookie 的完整单行值，而不是 Application 表格里某一个 Cookie 值；不要粘贴 cURL 或 `Set-Cookie` 响应头。
5. 在 Bob 将登录方式设为「手动 Cookie」，填写后验证。必要时填写同一浏览器的 User-Agent。

Cookie 就是登录凭证，**不要发到聊天、GitHub Issue、截图或公开日志里**。

## 如何工作

- 登录助手使用独立、非持久化的 `WKWebView` 打开豆包官网，不读取 Chrome、Edge、Safari 的现有 Cookie 数据库。
- 仅将助手窗口产生的豆包 Cookie 保存在 **macOS 钥匙串**。恢复时保留 Secure / HttpOnly 属性。
- Bob 与助手首次通过可见确认配对；后续使用随机 256 位本机令牌访问固定的 `127.0.0.1:17643`。
- 助手把适用于豆包翻译地址的 Cookie 和当前 WebView User-Agent 提供给已配对的 Bob。
- **原文仍由 Bob 直接发给豆包 HTTPS 接口**，不经过助手转发，更没有第三方翻译中转服务器。
- 插件解析豆包 SSE 事件，把译文转为 Bob 1.21 的纯文本显示格式。

助手不是密码管理器。登录态和本机配对令牌都是敏感信息；详见 [SECURITY.md](SECURITY.md)。官方网页本身可能加载其登录与 CDN 资源。

## 功能与限制

- 三种翻译服务可切换；是否可用取决于账号和上游服务。
- 支持简繁中文及英、日、韩、法、德、西、葡、俄、意、阿、泰、越、印尼、马来、土耳其、荷兰、波兰语。
- 支持取消、超时、SSE 接收、UTF-8 跨包处理及中文错误提示。
- 上游按条目返回译文，不保证逐字输出；保留上游输出的换行，不渲染 Markdown。
- 单次安全上限 12000 个 UTF-16 字符，部分 emoji 占两个；这是插件限制，不是官方额度声明。
- 登录失效时，助手模式会尝试打开官方登录页；仍需你本人完成扫码/验证，不会代输密码或绕过验证。
- 不是通用聊天 API，不支持自由问答、自定义模型或系统提示词。
- Bob 的 OCR 服务不受本插件替换。
- 不保证无限次数、长期可用或规避服务条款与账号限制。

## 故障排查

| 提示 | 处理 |
| --- | --- |
| 助手未启动 / 无法连接 | 打开 Doubao Login Helper，检查菜单栏；本机端口为 17643。 |
| 配对码 | 核对 Bob 和助手两处相同的 6 位码，允许后再次验证。 |
| 配对已失效 | 可能在助手中撤销了授权；重新验证并确认。 |
| 需要登录 | 在助手官方页面完成登录，再验证；“检测到凭证”不等于账号已通过翻译验证。 |
| `710012000` / `710012001` / `710022013` | 登录失效；重新登录。手动模式需重新复制 Cookie。 |
| HTTP 403 / 官方页面不兼容 | 先确认官网可用；助手内无法登录时改用手动模式。 |
| `710012007` / `676010003` / HTTP 429 | 请求过频或服务繁忙，稍后重试。 |
| `710022002` / `710022004` | 上游拒绝请求；检查内容或稍后重试。 |
| 17643 端口占用 | 退出重复的助手；不要把 Cookie 填到陌生程序提供的替代端口。 |

助手菜单提供「清除本机登录」和「撤销 Bob 配对」。清除本地 Cookie 不等于撤销豆包服务器上所有设备的会话；涉及凭证泄露时应使用豆包账号自身的退出/会话管理功能。

如果你用过本地定制的 0.1.0：公开版使用新的插件 identifier，属于新插件。安装并验证新服务后，再自行停用旧服务；不会擅自修改旧配置。
